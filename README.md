# NEON CLAW

Неоновый платформер про кибер-ниндзя: паркур по ночным крышам, катана,
когти и стражи, которые умеют блокировать.

Ориентиры: «Лабиринт отражений» Лукьяненко и «Нейромант» Гибсона — по
интонации; Tenchu и Splinter Cell — по терпению; Uncharted и Tomb Raider —
по удовольствию от лазания; Katana Zero — по короткому летальному размену;
Cyberpunk 2077 — по неону.

Вертикальный срез — один уровень, одна механика движения, один противник.
Задача среза не в объёме, а в ответе на единственный вопрос: приятно ли
это щупать. Если да — то же самое масштабируется уровнями.

## Играть

Игра собрана из ES-модулей, поэтому её нужно отдавать по HTTP, а не
открывать двойным щелчком:

```bash
npm start
```

Дальше `http://localhost:4231/`. Ни сборки, ни зависимостей, ни бэкенда —
сервер на шестьдесят строк нужен только для разработки, а выкладка это
обычная статика.

## Управление

| | |
|---|---|
| `A` `D` · `←` `→` | бег |
| `Space` · `↑` | прыжок; с виса — подтянуться; у стены — толчок |
| `J` · `X` | катана |
| `Shift` · `K` | рывок; вместе с `↓` — подкат |
| `S` · `↓` | спрыгнуть с помоста и с карниза |
| `R` · `Esc` · `M` | заново · пауза · звук |
| `F2` | показать хитбоксы |

## Из чего сделано ощущение

**Два тайла и три.** Прыжок поднимает ровно на 63 пикселя — это два тайла
с небольшим запасом и ни в коем случае не три. Всё, что выше двух, берётся
только когтями за кромку. На этой единственной разнице держится вся
вертикаль уровня: шахта в конце — это четыре кромки подряд, и пройти её
прыжками невозможно.

**Четыре глагола вместо одного.** Прыжок берёт 2 тайла вверх и 3,7 в длину,
когти — 3 тайла вверх, рывок добавляет 2,2 тайла к длине, подкат проходит
щель в один тайл, которая для бегущего наглухо закрыта. Стена превращает
вертикаль в дорогу: шахта шириной в 2–4 тайла проходится зигзагом до самого
верха, а шириной в 5 — уже нет. Каждое число — это отдельное правило для
того, кто рисует уровень, и все они проверены тестами, а не на глаз.

**Прощающие окна.** Койот-тайм (90 мс после схода с края) и буфер прыжка
(110 мс до приземления). Игрок никогда не замечает их присутствия — он
замечает только их отсутствие и называет это «управление тупит».

**Гарда стража.** Получив удар, страж вскидывает блок: сабля соскакивает
со звоном, урона нет, игрока отбрасывает. Каждый удар в поднятую гарду
продлевает её — долбить кнопку становится строго хуже, чем выждать. Зато
после того как гарда опускается, страж какое-то время не может закрыться
снова, и выждавший успевает положить два удара подряд. Ритм
«удар — пауза — два удара» получается из двух таймеров, без единой строчки
про «сложность».

**Замирание кадра.** 60 мс паузы на попадании. Без него удар — это просто
убыль цифры над врагом.

## Как это нарисовано

Спрайтов нет вообще: фигуры собраны из линий, город — из прямоугольников.
Для неона это не компромисс, а точное попадание — здесь всё и должно быть
светящимся контуром.

Свечение работает в два прохода. Всё яркое рисуется дважды: чётко на
основном холсте и толсто на уменьшенном втором, который потом размывается
и подмешивается сложением. Ядро линии остаётся резким, вокруг него
появляется ореол — именно так выглядит настоящая трубка, и именно этого не
даёт `shadowBlur`, который к тому же режет кадры.

Фон — три слоя параллакса, напечатанные в offscreen один раз при старте.
Генератор детерминированный: город должен быть одним и тем же между
перезапусками, иначе «а вон там была вывеска» перестаёт работать.

## Устройство

Логика отделена от отрисовки. Мир не знает, как он выглядит и как звучит:
он складывает события в списки, а рендер и звук их проигрывают.

| Путь | Зачем |
|---|---|
| `src/tuning.js` | Все числа, которыми игра ощущается, и объяснения к ним |
| `src/level.js` | Карта в ASCII и запросы к ней |
| `src/physics.js` | Тела, камень, поиск кромки |
| `src/player.js` | Движение, сабля, зацеп |
| `src/enemy.js` | Страж периметра и его гарда |
| `docs/asset-request.md` | ТЗ на ассеты для внешнего генератора |
| `src/world.js` | Правила встречи всего перечисленного |
| `src/camera.js` | Слежение с упреждением и мёртвой зоной |
| `src/backdrop.js` | Генератор города на фоне |
| `src/render.js` | Неон в два прохода |
| `src/audio.js` | Звук синтезом, без единого файла |
| `src/main.js` | Цикл, экраны, привязка ввода |

Уровень нарисован руками в `src/level.js`, а не сгенерирован. Плотность —
половина обаяния платформера: провал шириной ровно в три тайла, карниз
ровно на волосок выше прыжка, тайник, до которого надо догадаться лезть.
Такие вещи не выпадают из шума, их ставят по одной.

## Тесты

```bash
npm test
```

Проверяется не разметка, а замысел: что прыжок берёт два тайла и не берёт
три, что койот-тайм и буфер работают, что стена ловит падение и не съедает
собственный толчок, что подкат проходит там, где бег упирается лбом, что
гарда не пропускает урон и продлевается. И — главное — что уровень
проходится: каждый задуманный шаг вертикали выполняется симуляцией.

## Чего в срезе нет

Стелса — а он и есть главное в выбранных ориентирах: ни света, ни теней,
ни конусов зрения, ни тревоги. Гаджетов. Взлома и загадок. Второго уровня.
Музыки. Сохранений.

Ассеты для трёх районов заказываются отдельно: `docs/asset-request.md` —
готовое ТЗ для генератора, с проверенными числами движения внутри.
