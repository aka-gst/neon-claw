# NEON CLAW — задание на ассеты

Это ТЗ для агента-генератора. Всё, что здесь просят, — **данные, а не картинки**:
в игре нет ни одного растрового файла и не будет. Читай целиком до раздела
«Порядок работы» — там сказано, с чего начать и когда остановиться.

---

## 1. Что за игра

Кибер-ниндзя на ночных крышах, складах и рынках нижнего яруса. Он проходит
периметр, снимает стражей, крадёт данные и уходит. Паркур важнее боя:
перемещаться должно быть интересно само по себе.

Ориентиры по настроению — «Лабиринт отражений» Лукьяненко и «Нейромант»
Гибсона: сеть как обжитое место, а не как спецэффект; жаргон вместо пафоса;
город, в котором давно живут. По ощущению от игры — Tenchu и Splinter Cell
(тень, обход, терпение), Uncharted и Tomb Raider (лазание как удовольствие),
Katana Zero (короткий летальный размен), Cyberpunk 2077 (неон и вывески).

Визуально: **чёрный силуэт + светящийся контур**. Никаких текстур, никаких
градиентов внутри объектов. Всё, что видно, — это линии.

---

## 2. Жёсткие ограничения

- Только **чистый JSON**. Без комментариев, без висящих запятых, без
  `undefined`. Каждый файл обязан проходить `JSON.parse` без правок.
- **Никакого растра**: ни PNG, ни JPEG, ни base64, ни `data:`.
- **Никакого SVG-файла**. Формы описываются списком примитивов (см. ниже) —
  движок рисует их сам в canvas.
- Никаких новых зависимостей и никаких правок в `src/`. Ты отдаёшь только
  файлы из списка в разделе 6.
- Цвета **не указываются напрямую**. Вместо цвета — роль из раздела 4.
  Палитра живёт в коде, и менять её должно быть можно одним местом.

---

## 3. Единицы, координаты, размеры

| Что | Значение |
|---|---|
| Тайл | 24 × 24 пикселя |
| Экран | 480 × 270 логических пикселей = 20 × 11,25 тайла |
| Рост героя | 15 × 30 пикселей (чуть выше тайла) |
| Рост стража | 16 × 30 |

**Тайлы и глифы**: координаты внутри клетки, `0..24`, ось `y` вниз (как в
canvas). Начало — левый верхний угол клетки.

**Фигуры и анимация**: начало координат — **между ступнями**, ось `x` вперёд
(герой всегда рисуется смотрящим вправо, разворот делает движок), ось `y`
**вверх отрицательная**. То есть макушка стоящего героя — это `y = -30`,
бедро — примерно `-14`, плечо — `-23`.

---

## 4. Роли вместо цветов

Каждый примитив обязан иметь `role` из этого списка и ничего кроме:

| Роль | Что это | Читается как |
|---|---|---|
| `edge` | верхняя грань опоры | «сюда можно встать» |
| `side` | боковая грань массива | «об это упрёшься» |
| `body` | заливка массива | глубина, не свет |
| `detail` | мелочь внутри: окна, швы, заклёпки | обжитость |
| `wire` | провода, тросы, перила, трубы | «за это цепляются» |
| `sign` | вывеска | город |
| `hot` | опасность | «убьёт» |
| `loot` | добыча | «возьми» |
| `data` | цель, ядро, терминал | «ради этого пришёл» |
| `foe` | враг и всё, что от него | «не подходи» |

Роль определяет цвет, толщину и свечение. Одна и та же форма с ролью `edge`
и с ролью `hot` — это разное сообщение игроку, и путать их нельзя.

---

## 5. Правила уровня — это физика, а не вкус

Числа ниже **измерены на текущей сборке**, а не придуманы. Уровень, который
им противоречит, непроходим.

| Движение | Достаёт |
|---|---|
| Прыжок вверх | **2 тайла** (63 px) |
| Прыжок в длину с разбега | **3,7 тайла** |
| Зацеп когтями за кромку | **3 тайла** вверх |
| Рывок по горизонтали | **+2,2 тайла** |
| Прыжок + рывок в длину | **5,9 тайла** |
| Подкат | щель высотой **1 тайл** |
| Стоя | нужно **2 тайла** высоты |

Отсюда правила, которые нельзя нарушать:

- **Провал в 3 тайла** — обязательный проход, берётся всеми.
  **4–5 тайлов** — только с рывком. **6 и больше** — тупик, так не делают.
- **Уступ в 2 тайла** — прыжком. **В 3** — только когтями за кромку.
  Кромка должна быть настоящей: над ней обязана быть пустота хотя бы в тайл,
  иначе цепляться не за что.
- **Шахта для зигзага по стенам — строго 2, 3 или 4 тайла в ширину.**
  При 5 и больше зигзаг не собирается: герой не долетает до противоположной
  стены на нужной высоте. Это проверено, не спорь с этим.
- **Щель в 1 тайл** — единственный вход, который запирается от бега.
  Ей и запирай тайники: словами объяснять ничего не надо.
- Тупиковых карманов быть не должно. Из любой точки, куда игрок может
  попасть, должен быть выход обратно.

## 6. Что именно нужно, по приоритету

Ниже — точные пути файлов. Имена не менять.

### Очередь 1 — тайлсеты (самое нужное)

```
assets/tiles/roofs.json
assets/tiles/warehouse.json
assets/tiles/market.json
```

Три района, три характера. **Крыши**: бетон, парапеты, антенны, кондиционеры,
натянутые тросы. **Склад**: гофрированный металл, рёбра жёсткости, контейнеры,
цепи, решётчатые настилы. **Рынок**: навесы, ткань, ящики, гирлянды,
иероглифические вывески, теснота.

Формат:

```json
{
  "district": "roofs",
  "tile": 24,
  "kinds": {
    "solid.top": [
      [ { "op": "line", "pts": [[0, 2], [24, 2]], "role": "edge", "width": 2.2 },
        { "op": "rect", "x": 3, "y": 6, "w": 4, "h": 3, "role": "detail" } ],
      [ { "op": "line", "pts": [[0, 2], [24, 2]], "role": "edge", "width": 2.2 },
        { "op": "line", "pts": [[16, 2], [16, 9]], "role": "wire", "width": 1.2 } ]
    ],
    "solid.body": [ [ ... ] ],
    "oneway":     [ [ ... ] ],
    "ladder":     [ [ ... ] ],
    "hazard":     [ [ ... ] ],
    "prop":       [ [ ... ] ]
  }
}
```

Каждый `kind` — **массив вариантов**, каждый вариант — список примитивов.
Движок выбирает вариант детерминированно по координатам клетки, чтобы стена
не выглядела штампом. Дай 3–4 варианта на `solid.top` и `solid.body`,
2–3 на остальные, и **6–10 вариантов на `prop`** — это чистый декор, который
ставится поверх и делает район собой.

Примитивы и их поля:

| `op` | Поля |
|---|---|
| `line` | `pts` (2 и более точек), `width` |
| `rect` | `x`, `y`, `w`, `h`, `fill` (bool) |
| `poly` | `pts`, `close` (bool), `fill` (bool), `width` |
| `arc` | `cx`, `cy`, `r`, `a0`, `a1`, `width` |

Плюс обязательное `role` у каждого. Углы в радианах. Все координаты в
пределах `-2 .. 26` (немного за клетку можно — так тайлы сшиваются).

**Важно про `solid.top`**: верхняя грань — это единственное, по чему игрок
на бегу понимает, куда можно встать. Она обязана быть сплошной линией по
всей ширине клетки и не тонуть в декоре.

### Очередь 2 — фоны

```
assets/backdrop/roofs.json
assets/backdrop/warehouse.json
assets/backdrop/market.json
```

Параллакс печатается один раз в буфер при старте. Ты описываешь только правила
генерации:

```json
{
  "district": "roofs",
  "sky": [["#05060f", 0], ["#0a0b1c", 0.55], ["#120a22", 1]],
  "glow": { "at": [0.35, 0.72], "radius": 380, "color": "#ff2d95", "alpha": 0.34 },
  "layers": [
    {
      "parallax": [0.12, 0.05],
      "baseline": 0.86,
      "height": [42, 120],
      "width": [26, 80],
      "gap": [4, 18],
      "fill": "#0a0d1e",
      "edge": "rgba(124, 77, 255, 0.55)",
      "windows": 0.10,
      "signs": 0.0,
      "cables": 0,
      "seed": 1
    }
  ]
}
```

Три слоя на район: дальний, средний, ближний. `parallax` — доли смещения по
x и y; ближний слой быстрее. `baseline` — доля высоты экрана, на которой стоят
дома. `windows` — вероятность зажжённого окна. `signs` — вероятность
вертикальной вывески. Здесь цвета указываются напрямую: фон не участвует в
игровой читаемости, это настроение.

Районы обязаны отличаться на глаз за полсекунды. Крыши — простор и глубина.
Склад — низкий потолок, мало неба, тяжёлые массы. Рынок — тесно, ярко,
много мелких огней.

### Очередь 3 — глифы интерфейса

```
assets/glyphs/ui.json
```

```json
{ "size": 16, "icons": { "shard": [ { "op": "poly", "pts": [...], "role": "data" } ] } }
```

Координаты `0..16`, `y` вниз. Нужны: `shard`, `core`, `alarm`, `seen`,
`hidden`, `noise`, `hook`, `emp`, `decoy`, `crawler`, `life`, `checkpoint`,
`terminal`, `katana`. Каждый — 3–8 примитивов, узнаваемый силуэтом,
без мелочи меньше 2 пикселей.

### Очередь 4 — текст

```
assets/text/ru.json
```

```json
{
  "districts": {
    "roofs": { "title": "", "subtitle": "", "intro": "" }
  },
  "shards": [ { "id": "", "title": "", "body": "" } ],
  "barks": { "calm": [], "suspicious": [], "alerted": [], "lost": [] },
  "terminals": [ { "id": "", "lines": [] } ],
  "hints": { "wall": "", "dash": "", "slide": "", "ledge": "" }
}
```

Тон: сухо, коротко, без пафоса и без объяснений. Мир давно живёт своей жизнью
и не собирается ничего рассказывать игроку — тот подслушивает. Реплики стражей
(`barks`) — по 6–8 штук на состояние, длиной в три-пять слов. Осколки данных
(`shards`) — 12 штук, каждый 2–4 предложения: обрывок переписки, служебная
записка, кусок чьего-то дневника. Подсказки (`hints`) — одна строка, про
действие, а не про клавишу.

Русский язык. Никакого «киберпространства» и «матрицы» — слова должны быть
рабочие, как у людей, которые этим живут.

### Очередь 5 — уровни (сырьё, не финал)

```
assets/levels/01-roofs.json
assets/levels/02-warehouse.json
assets/levels/03-market.json
```

```json
{
  "id": "01-roofs",
  "district": "roofs",
  "tile": 24,
  "legend": {
    "#": "solid", "=": "oneway", "H": "ladder", "^": "hazard",
    "p": "spawn", "e": "enforcer", "o": "chip", "*": "core", "X": "exit"
  },
  "map": ["........", "########"],
  "route": [
    "с крыши направо, провал в 3 тайла — прыжком",
    "стена в 3 тайла — когтями за кромку",
    "шахта шириной 3 тайла — зигзагом до самого верха"
  ],
  "secrets": [ { "at": [47, 11], "kind": "core", "reachedBy": "щель в 1 тайл, подкатом" } ]
}
```

Размер — 72 × 30 клеток, все строки одной длины. Поле `route` **обязательно**:
опиши задуманный путь по шагам, каждый шаг — одно движение из таблицы в
разделе 5. Это единственный способ проверить, что уровень проходим, не запуская
его. Уровень без честного `route` не принимается.

Каждый район вводит **ровно одну новую идею** и не больше: крыши — зигзаг по
стенам, склад — подкат и низкие проходы, рынок — теснота и обзор.

### Очередь 6 — звук

```
assets/audio/kit.json
```

Звук синтезируется на месте, файлов нет. Опиши голоса:

```json
{
  "voices": {
    "shard": [ { "wave": "square", "from": 880, "to": 1320, "dur": 0.1, "gain": 0.13 } ],
    "alarm": [ { "wave": "sawtooth", "from": 440, "to": 440, "dur": 0.3, "gain": 0.2 },
               { "noise": true, "freq": 900, "q": 0.6, "dur": 0.25, "gain": 0.12 } ]
  }
}
```

Нужны: `shard`, `core`, `alarm`, `spotted`, `lost`, `hack.start`, `hack.ok`,
`hack.fail`, `takedown`, `gadget.throw`, `door`, `checkpoint`. По 1–3 слоя на
голос, длительность до 0,4 секунды. Музыку не проси и не пиши — её здесь нет.

### Очередь 7 — анимация (рискованно, только после образца)

```
assets/anim/ninja.json
```

```json
{
  "name": "ninja",
  "height": 30,
  "clips": {
    "run": {
      "fps": 14,
      "loop": true,
      "frames": [
        { "strokes": [
          { "role": "limb",  "pts": [[0, -14], [4, -7], [7, 0]] },
          { "role": "limb",  "pts": [[0, -14], [-4, -7], [-7, -3]] },
          { "role": "torso", "pts": [[-3, -13], [3, -13], [2.6, -23], [-2.6, -23]], "close": true }
        ] }
      ]
    }
  }
}
```

Роли штрихов здесь свои: `limb`, `torso`, `hood`, `scarf`, `visor`, `blade`,
`claw`. Клипы: `idle`, `run`, `jump.rise`, `jump.fall`, `land`, `wall.slide`,
`wall.push`, `ledge.hang`, `ledge.climb`, `dash`, `slide`, `attack`, `hurt`,
`death`, `hack`. По 4–8 кадров на клип, кроме `attack` — там минимум 3 кадра
с чётко разными фазами (замах, удар, возврат).

**Это самая ненадёжная часть задания.** Сейчас позы считаются кодом и работают.
Данные заменят их только если окажутся лучше. Поэтому: сначала пришли **только
`idle` и `run`**, дождись ответа, и лишь потом делай остальное.

---

## 7. Порядок работы

1. Сделай **очередь 1 целиком** (три файла тайлсетов) и остановись.
2. После подтверждения — очереди 2 и 3.
3. Дальше 4, 5, 6 в любом порядке.
4. Очередь 7 — только по отдельной просьбе и только с образца.

Не делай всё сразу. Одна ошибка в понимании формата, размноженная на
пятнадцать файлов, — это дороже, чем лишний круг.

---

## 8. Критерии приёмки

- Файл проходит `JSON.parse` без единой правки.
- Все `role` — из таблицы в разделе 4 (или из списка ролей анимации).
- Координаты в заявленных границах.
- У каждого `kind` в тайлсете есть хотя бы 2 варианта.
- У уровня все строки `map` одной длины, есть `p` и `X`, есть честный `route`.
- Ничего не выходит за пределы «линии и заливки»: ни текстур, ни градиентов
  внутри объектов, ни шрифтов.

## 9. Чего не надо

Картинок. SVG-файлов. Шрифтов. Библиотек. Правок в `src/`. Музыки.
Английского текста в игровых строках. Объяснений игроку, что такое киберпанк.
