## 2. Правила поставки

- Только **чистый JSON**: без комментариев, без висящих запятых. Каждый файл
  обязан проходить `JSON.parse` без единой правки.
- **Один запрос — одна очередь.** Не присылай всё разом: заказ на тридцать
  файлов однажды вернулся одним контактным листом вместо серии.
- Цвета не указываются нигде: вместо цвета — **роль**. Палитра живёт в коде,
  и сменить вид всего района должно быть можно правкой одной таблицы.
- Русский язык во всех игровых строках.
- Складывай зипом в `~/dev/Zakriva/deliverables/`.

## 3. Общий язык примитивов

Он один для тайлов, фигур, глифов и эффектов.

| `op` | Поля |
|---|---|
| `line` | `pts` (две и более точек), `width` |
| `rect` | `x`, `y`, `w`, `h`, `fill` |
| `poly` | `pts`, `close`, `fill`, `width` |
| `arc` | `cx`, `cy`, `r`, `a0`, `a1`, `width` |

У каждого примитива обязательное `role`. Углы в радианах.

**Роли геометрии** (тайлы, декор): `edge` — верхняя грань, «сюда можно
встать»; `side` — боковая и нижняя, «об это упрёшься»; `body` — заливка
массива; `detail` — мелочь внутри; `wire` — провода, тросы, трубы;
`sign` — вывеска; `hot` — опасность; `loot` — добыча; `data` — цель;
`foe` — враг.

**Роли фигур** (персонажи, оружие): `limb` — руки и ноги; `torso` — корпус;
`head` — голова и шлем; `cloth` — плащ, шарф, ткань; `visor` — светящаяся
щель глаза; `blade` — клинок; `metal` — железо, когти, пряжки; `glow` —
чистый свет без тела; `accent` — фирменный цвет персонажа.

Золото значит «возьми», красный — «убьёт». Для декора их использовать
нельзя: игрок читает цвет быстрее формы.

## 4. Числа игры

**Измерено на текущей сборке.** Уровень, который им противоречит, непроходим.

Тайл 24 пикселя. Рост героя 15×30, стража 16×30.

| Движение | Достаёт |
|---|---|
| Прыжок вверх | **2 тайла** |
| Прыжок в длину с разбега | **3,7 тайла** |
| Зацеп когтями за кромку | **3 тайла** вверх |
| Рывок по горизонтали | **+2,2 тайла** |
| Прыжок + рывок в длину | **5,9 тайла** |
| Подкат | щель высотой **1 тайл** |
| Стоя | нужно **2 тайла** высоты |
| Стрела плоско | падает через **5 тайлов** |
| Стрела навесом | до **16 тайлов** |

Правила, которые нельзя нарушать:

- Провал в **3 тайла** — общий проход. **4–5** — только с рывком.
  **6 и больше** — тупик, так не делают.
- Уступ в **2 тайла** — прыжком, в **3** — только когтями. Над кромкой
  обязана быть пустота хотя бы в тайл.
- **Шахта для зигзага по стенам — строго 2, 3 или 4 тайла в ширину.**
  При 5 зигзаг не собирается: герой не долетает до противоположной стены.
- **Щель в 1 тайл** — единственный проход, закрытый для бегущего.
- Тупиковых карманов быть не должно.

**Зрение стража.** Конус вперёд на 170 пикселей, полувысота
`20 + 0,22 × дальность`. Спиной не видит. Сквозь стену не видит.

**Слух.** Стены шум не держат. Бег 92, приземление 150, рывок 128, подкат
112, скрежет по стене 68, звон о гарду 265, стрела в стену 135, тихое
снятие 54, смерть в бою 205. **Крадущийся шаг — ноль.**

**Бой.** У героя две жизни, у стража две. Со спины и сверху — снятие с
одного удара. В лоб — два удара с гардой между ними.

# Очередь A — фигуры персонажей

Самое крупное и самое ценное. Сейчас герой нарисован шестьюдесятью
строчками кода: узнаётся, но беден. Данные снимут этот потолок.

```
assets/figures/ninja.json
assets/figures/guard.json
assets/figures/heavy.json
assets/figures/scout.json
assets/figures/sniper.json
assets/figures/hound.json
```

**Система координат.** Начало — между ступнями. Ось `x` вперёд: фигура
всегда рисуется смотрящей вправо, разворот делает движок. Ось `y` вверх
**отрицательная**: макушка стоящего — это `-height`.

Координаты задаются **в долях роста**, а не в пикселях: `"height": 1` и
всё внутри в пределах примерно `-1,15` по вертикали. Тогда фигура
переживёт смену масштаба игры, а она возможна.

```json
{
  "name": "ninja",
  "height": 1,
  "width": 0.5,
  "palette": { "rim": "accent", "cloth": "cloth", "eye": "visor" },
  "poses": {
    "idle": {
      "loop": true,
      "fps": 6,
      "frames": [
        { "strokes": [
          { "op": "line", "pts": [[0,-0.47],[0.07,-0.23],[0.10,0]], "role": "limb", "width": 0.08 },
          { "op": "poly", "pts": [[-0.11,-0.44],[0.11,-0.44],[0.09,-0.77],[-0.09,-0.77]], "role": "torso", "close": true, "fill": true, "width": 0.07 }
        ] }
      ]
    }
  }
}
```

**Позы, которые нужны каждому персонажу:**

`idle`, `walk`, `run`, `jump.rise`, `jump.fall`, `land`, `hurt`, `death`.

**Дополнительно герою:** `wall.slide`, `wall.push`, `ledge.hang`,
`ledge.climb`, `dash`, `slide`, `attack` (минимум 3 кадра с чётко разными
фазами: замах, удар, возврат), `bow.draw`, `bow.release`, `crouch`.

**Дополнительно стражам:** `patrol`, `suspect` (озирается), `alert`,
`guard` (гарда поднята), `windup`, `attack`, `takedown` (как его снимают).

По 4–8 кадров на движущиеся позы, 1–2 на статичные. Между кадрами движок
не интерполирует: рисуй так, чтобы читалось покадрово.

**Кто эти шестеро:**

| Файл | Кто | Силуэт |
|---|---|---|
| `ninja` | герой | капюшон, длинный шарф, катана за спиной, когти на предплечьях, одна циановая щель визора |
| `guard` | рядовой страж | шлем с гребнем, броневые пластины, клинок на поясе, красная щель |
| `heavy` | тяжёлый | вдвое шире, щит на предплечье, шагает медленно, гарду держит долго |
| `scout` | разведчик | лёгкий, сутулый, с фонарём-визором, узкий силуэт |
| `sniper` | стрелок | длинный ствол, стоит неподвижно, тонкий |
| `hound` | пёс | четвероногий, низкий, вытянутый, без визора — светятся ноздри |

Силуэты обязаны различаться **на глаз при высоте в тридцать пикселей**.
Не деталями, а формой: ширина, наклон, характерный выступ. Если два
персонажа отличаются только цветом, работа не сделана.

«киберпространства» и «матрицы»: слова рабочие, как у тех, кто этим живёт.

## Порядок

A → C → D → B → E → F → G → H.

Фигуры первыми, потому что они меняют вид игры сильнее всего остального
вместе взятого. Глифы и тексты сразу за ними: они дешёвые и закрывают
самые заметные дыры. Оружие имеет смысл после фигур — оно к ним крепится.

Не присылай следующую очередь, не дождавшись ответа по предыдущей: формат
проверяется на первой поставке, и ошибка в понимании, размноженная на
шесть файлов, дороже лишнего круга.

## Приёмка

- Файл проходит `JSON.parse` без правок.
- Все `role` — из раздела 3.
- Координаты фигур в долях роста, не в пикселях.
- Силуэты шести персонажей различимы формой при высоте 30 пикселей.
- Реплики не длиннее пяти слов.
- Глифы узнаются при уменьшении до 16 пикселей.
- У уровня строки одной длины, есть `p`, `X`, минимум два `C` и честный
  `route`; обозначений ровно восемь.

## Чего не надо

Растровых картинок и спрайтов. Английского в игровых строках. Музыки.
Правок в `src/`. Сюжета с большой буквы — мир рассказывает о себе
обрывками, и этого достаточно.
