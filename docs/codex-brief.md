# NEON CLAW — что нужно сделать

Одно задание на всё. Читай подряд: раздел 1 говорит, чего делать **не** надо,
раздел 3 — числа, без которых уровни получатся непроходимыми.

Игра: кибер-ниндзя на ночных крышах, складах и рынках. Стелс, паркур,
короткий летальный размен. Чёрный силуэт плюс светящийся контур, ни одного
растрового спрайта. Всё, что здесь просят, — **данные**.

## 2. Правила поставки

- Только **чистый JSON**: без комментариев, без висящих запятых. Каждый файл
  обязан проходить `JSON.parse` без единой правки.
- **Один запрос — одна очередь.** Не присылай всё разом: в прошлый раз
  заказ на тридцать файлов вернулся одним контактным листом.
- Цвета не указываются нигде: вместо цвета — роль. Палитра живёт в коде.
- Русский язык во всех игровых строках.
- Складывай зипом в `~/dev/Zakriva/deliverables/`.

## 3. Числа игры

Это **измерено на текущей сборке**, а не придумано. Уровень, который им
противоречит, непроходим.

Тайл 24 пикселя. Рост героя 15×30, стража 16×30.

| Движение | Достаёт |
|---|---|
| Прыжок вверх | **2 тайла** |
| Прыжок в длину с разбега | **3,7 тайла** |
| Зацеп когтями за кромку | **3 тайла** вверх |
| Рывок по горизонтали | **+2,2 тайла** |
| Прыжок + рывок в длину | **5,9 тайла** |
| Подкат | щель высотой **1 тайл** |
| Стоя | нужно **2 тайла** высоты |

Правила, которые нельзя нарушать:

- Провал в **3 тайла** — общий проход. **4–5** — только с рывком.
  **6 и больше** — тупик, так не делают.
- Уступ в **2 тайла** — прыжком, в **3** — только когтями. Над кромкой
  обязана быть пустота хотя бы в тайл, иначе цепляться не за что.
- **Шахта для зигзага по стенам — строго 2, 3 или 4 тайла в ширину.**
  При 5 зигзаг не собирается: герой не долетает до противоположной стены.
- **Щель в 1 тайл** — единственный проход, закрытый для бегущего. Ей и
  запирай тайники.
- Тупиковых карманов быть не должно: из любой точки есть выход обратно.

**Зрение стража.** Конус вперёд на 170 пикселей, полувысота `20 + 0,22 × дальность`.
Спиной не видит вовсе. Сквозь стену не видит. Заметив — помнит 1,6 секунды
и следит даже за спиной.

**Слух.** Стены шум не держат. Радиусы: бег 92, приземление 150, рывок 128,
подкат 112, скрежет по стене 68, звон о гарду 265, тихое снятие 54, смерть
в бою 205. **Крадущийся шаг — ноль.**

**Бой.** У героя две жизни, у стража две. Со спины и сверху — снятие с
одного удара. В лоб — два удара, между ними страж закрывается гардой, и
удар в гарду даёт звон, который слышно на весь сектор.

## Очередь 1 — тексты (самое нужное)

```
assets/text/ru.json
```

Сейчас стражи немые, а мир ничего о себе не говорит. Это самая заметная
дыра.

```json
{
  "districts": {
    "roofs":     { "title": "", "subtitle": "", "intro": "" },
    "warehouse": { "title": "", "subtitle": "", "intro": "" },
    "market":    { "title": "", "subtitle": "", "intro": "" }
  },
  "barks": {
    "calm": [], "suspect": [], "alert": [], "lost": [], "death": []
  },
  "shards": [ { "id": "", "title": "", "body": "" } ],
  "terminals": [ { "id": "", "lines": [] } ],
  "hints": {
    "wall": "", "ledge": "", "dash": "", "slide": "",
    "walk": "", "takedown": "", "guard": "", "noise": ""
  },
  "notices": {
    "clang": "", "takedownBack": "", "takedownAbove": "",
    "checkpoint": "", "core": "", "spotted": "", "lostYou": ""
  }
}
```

**Реплики стражей (`barks`)** — по 8 штук на состояние, **не длиннее пяти
слов**: они всплывают над головой в кадре высотой 250 пикселей.
`calm` — скука на посту. `suspect` — услышал и идёт проверять.
`alert` — увидел. `lost` — потерял и злится. `death` — последнее.

**Осколки данных (`shards`)** — 12 штук по 2–4 предложения: обрывок
переписки, служебная записка, кусок чужого дневника. Не сюжет, а следы
чужой жизни, на которые игрок наткнулся.

**Терминалы (`terminals`)** — 6 штук по 3–6 строк. Это то, что читаешь с
чужого экрана: заявки, отказы, переписка смены.

**Подсказки (`hints`)** — одна строка, про действие, а не про клавишу.
Плохо: «нажми Shift». Хорошо: «в щель под плитой проходят только подкатом».

**Уведомления (`notices`)** — короткие реплики самой игры в момент события.
Они заменят строки, зашитые сейчас в код.

Тон: сухо, коротко, без пафоса. Мир давно живёт своей жизнью и не
собирается ничего объяснять — игрок подслушивает. Ориентиры по интонации:
«Лабиринт отражений» Лукьяненко и «Нейромант» Гибсона. Никакого
«киберпространства» и «матрицы»: слова должны быть рабочие, как у людей,
которые этим живут.

## Очередь 2 — глифы интерфейса

```
assets/glyphs/ui.json
```

Формат ровно тот же, что в тайлсетах, только клетка 16×16 и `y` вниз:

```json
{
  "size": 16,
  "icons": {
    "shard": [
      { "op": "poly", "pts": [[8,2],[14,8],[8,14],[2,8]], "role": "loot", "close": true, "width": 1.5 }
    ]
  }
}
```

Примитивы: `line` (`pts`, `width`), `rect` (`x`,`y`,`w`,`h`,`fill`),
`poly` (`pts`,`close`,`fill`,`width`), `arc` (`cx`,`cy`,`r`,`a0`,`a1`,`width`).
У каждого обязательное `role` из списка: `edge`, `side`, `body`, `detail`,
`wire`, `sign`, `hot`, `loot`, `data`, `foe`.

Нужны: `shard`, `core`, `alarm`, `seen`, `heard`, `hidden`, `quiet`,
`checkpoint`, `terminal`, `katana`, `claw`, `bow`, `arrow`, `life`, `exit`.

По 3–8 примитивов на глиф. **Читаемость на 16 пикселях важнее красоты:**
если силуэт не узнаётся уменьшённым, глиф не годится, каким бы нарядным
ни был. Ничего тоньше одного пикселя и мельче двух.

## Очередь 3 — звук

```
assets/audio/kit.json
```

Звук синтезируется на месте, файлов нет. Опиши голоса слоями:

```json
{
  "voices": {
    "pickup": [
      { "wave": "square", "from": 880, "to": 1320, "dur": 0.1, "gain": 0.13, "delay": 0 }
    ],
    "alarm": [
      { "wave": "sawtooth", "from": 440, "to": 440, "dur": 0.3, "gain": 0.2, "delay": 0 },
      { "noise": true, "freq": 900, "q": 0.6, "dur": 0.25, "gain": 0.12, "delay": 0.05 }
    ]
  }
}
```

`wave` — один из `square`, `triangle`, `sawtooth`, `sine`. Слой с
`"noise": true` — полосовой шум вместо тона. До трёх слоёв на голос,
длительность до 0,45 секунды.

Нужен **весь набор целиком**, чтобы он звучал как набор, а не как то, что
наросло: `jump`, `land`, `swing`, `ledge`, `walljump`, `dash`, `slide`,
`scrape`, `hit`, `clang`, `kill`, `takedown`, `heard`, `spotted`, `pickup`,
`core`, `checkpoint`, `retry`, `hurt`, `fall`, `win`, `lose`, `bow.draw`,
`bow.release`, `arrow.hit`.

Смысловые требования: `takedown` тише `hit` — оно тихое по определению.
`clang` неприятнее всех: это провал. `heard` — короткий вопрос, а не
тревога: ещё можно уйти.

## Очередь 4 — уровни

```
assets/levels/02-warehouse.json
assets/levels/03-market.json
```

```json
{
  "id": "02-warehouse",
  "district": "warehouse",
  "tile": 24,
  "legend": {
    "#": "solid", "=": "oneway",
    "p": "spawn", "e": "enforcer",
    "o": "chip", "*": "core", "C": "checkpoint", "X": "exit"
  },
  "map": ["........", "########"],
  "route": [
    "с пола направо, провал в 3 тайла — прыжком",
    "плита на высоте 2 тайлов, под ней щель в 1 — подкатом",
    "шахта шириной 3 тайла — зигзагом до верха"
  ],
  "secrets": [ { "at": [47, 11], "kind": "core", "reachedBy": "подкатом под плиту" } ]
}
```

Размер 84×32, все строки `map` одной длины. Обозначений **ровно восемь**,
как в легенде: лестниц и опасностей движок пока не понимает, и карта с
ними работать не будет.

Поле `route` **обязательно**: опиши задуманный путь по шагам, каждый шаг —
одно движение из таблицы раздела 3. Это единственный способ проверить
проходимость, не запуская. Уровень без честного `route` не принимается.

**Каждый уровень вводит ровно одну новую идею и не больше.** Крыши уже
заняты зигзагом по стенам. Складу отдай тесноту и низкие проходы —
подкат как основной глагол. Рынку — обзор: много коротких линий видимости,
где шум важнее скорости.

Ставь стражей так, чтобы **у каждой развилки обе ветки были честными**:
тихий путь длиннее, быстрый громче. Патруль, мимо которого нельзя пройти
никак, — ошибка проектирования, а не сложность.

## Приёмка

- Файл проходит `JSON.parse` без правок.
- Все `role` — из списка раздела «Очередь 2».
- Реплики стражей не длиннее пяти слов.
- Глифы узнаются при уменьшении до 16 пикселей.
- У уровня строки `map` одной длины, есть `p`, `X`, хотя бы два `C`, и
  честный `route`.
- В картах нет обозначений вне легенды.

## Чего не надо

Картинок и спрайтов. Покадровой анимации. Английского в игровых строках.
Музыки. Правок в `src/`. Сюжета с большой буквы — мир рассказывает о себе
обрывками, и этого достаточно.
